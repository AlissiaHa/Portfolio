# Alissia Haldemann – Portfolio

Statische Portfolio-Website für GitHub Pages. Kein Build und keine Installation nötig. Alle Pfade funktionieren auch unter `/Portfolio/`.

## Lokal ansehen

`index.html` direkt im Browser öffnen oder im Projektordner `python3 -m http.server 8000` starten und http://localhost:8000 öffnen.

## Auf GitHub Pages veröffentlichen

1. Die Dateien in den Hauptbranch `main` des Repositorys hochladen.
2. Im GitHub-Repository **Settings → Pages** öffnen.
3. Bei **Build and deployment → Source** die Option **Deploy from a branch** wählen.
4. Branch **main**, Ordner **/(root)** wählen und speichern.
5. Nach erfolgreicher Bereitstellung ist die Website unter https://AlissiaHa.github.io/Portfolio/ erreichbar.

## Inhalte bearbeiten

- `index.html`: Texte, Projektbeschreibungen, Projektlinks und Bilder. Jedes Projekt steht in einem eigenen `<details>`-Element.
- `styles.css`: Farben (am Anfang als Variablen), Typografie und Layout.
- `script.js`: Projektfilter und Direktlinks. Ohne JavaScript bleiben alle Projekte und Details zugänglich.
- `assets/`: Optimierte Bilder und das textbasierte Favicon.

### Noch zu ergänzen

- Öffentliche E-Mail-Adresse: Der Kontaktbereich verweist vorläufig auf die Bewerbungsunterlagen.
- Originalvorschaubilder für Mood Mirror und Hot n Cold: Aktuell werden bewusst typografische Titelbilder eingesetzt, keine erfundenen Arbeitsproben.
- Einzelbilder der Tanzshow statt der gelieferten Collagen sind optional möglich.
- Vor Veröffentlichung Bildrechte und gewünschte Urheberangaben für alle verwendeten Projektfotos prüfen.
